# Changelog

All notable changes to Interactive Product Showcase will be documented in this file.

## [1.0.0] - 2024-12-23

### Added
- Initial release
- Interactive hotspot functionality
- WooCommerce product integration
- Customizable design settings (colors, button text)
- Drag-and-drop hotspot positioning
- Product search modal
- Shortcode support
- Responsive design
- Multi-language ready
- WordPress 6.9 compatibility

### Features
- Design tab for customizing colors and button text
- Add Image tab for creating showcases with hotspots
- Images tab for managing all showcases
- Product search with WooCommerce integration
- Custom product descriptions
- Visual hotspot editor
- Copy shortcode functionality
- Edit and delete showcases

### Security
- Nonce verification for all AJAX requests
- Capability checks for admin functions
- Data sanitization and validation
- SQL injection prevention
- XSS protection
